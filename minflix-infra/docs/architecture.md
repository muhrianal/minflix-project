# Architecture (prod)

```
Browser ──https──► CloudFront (<cf-domain>.cloudfront.net)
                     ├─ /          ► S3 frontend bucket   (OAC, private; SPA rewrite function)
                     ├─ /hls/*     ► S3 media bucket      (OAC, private; only hls/* readable)
                     └─ /api/*     ► ALB (http:80, CloudFront IPs only) ► ECS api (Fargate :8080)
Browser ──presigned PUT──► S3 media bucket  raw/...      (CORS: CloudFront origin only)

ECS api ──► DocumentDB (private subnets, TLS)
        ──► Amazon MQ RabbitMQ (private subnets, amqps 5671) ──► ECS worker (FFmpeg) ──► S3 hls/ + DocumentDB
```

```
VPC 10.0.0.0/16, 2 AZs
├── public subnets  10.0.0.0/24, 10.0.1.0/24   route 0.0.0.0/0 → IGW
│     ALB, ECS api tasks, ECS worker tasks (public IPs, no inbound except ALB → api:8080)
└── private subnets 10.0.10.0/24, 10.0.11.0/24 no internet route
      DocumentDB (27017 from ECS), Amazon MQ broker (5671 from ECS)
```

## Components
**CloudFront.** One distribution and one domain for everything the browser loads: the FE, the API and the HLS files. Because the FE and API share an origin, the FE calls `/api/...` with relative URLs and no CORS is needed for the API. Viewers always get HTTPS (default `*.cloudfront.net` certificate). The default behavior serves the FE bucket; a small CloudFront Function rewrites extension-less paths like `/watch/abc` to `/index.html` so client-side routes survive a refresh. `/hls/*` is cached (`CachingOptimized`); `/api/*` is not cached and forwards all viewer headers except Host.

**S3 media bucket.** Private. `raw/` receives uploads straight from the browser through presigned PUT URLs (CORS allows only the CloudFront origin). `hls/` holds the worker's output and is readable only by this CloudFront distribution (Origin Access Control + bucket policy on `hls/*`).

**S3 frontend bucket.** Private; holds the FE build, readable only by the distribution.

**ALB.** Public, HTTP:80, reachable only from CloudFront's origin-facing IP ranges (managed prefix list). Forwards to the api tasks on 8080 and health-checks `GET /actuator/health`.

**ECS Fargate api.** The Spring Boot API (profile `prod`). Issues JWTs, stores metadata in DocumentDB, presigns uploads, publishes transcode jobs.

**ECS Fargate worker.** The same image with profile `prod,worker` and no web server. Consumes jobs one at a time, runs FFmpeg (2 vCPU / 4 GB / 50 GiB disk by default), writes `hls/` and marks videos READY.

**DocumentDB.** MongoDB-compatible database for users and videos. Private subnets, TLS required.

**Amazon MQ for RabbitMQ.** The durable `transcode` queue between api and worker. Private, amqps on 5671.

**Secrets Manager.** `minflix-prod/mongodb-uri`, `minflix-prod/rabbitmq-password`, `minflix-prod/jwt-secret`, generated by Terraform and injected into the tasks by ECS.

**ECR.** Repository `minflix-be` with the single backend image (linux/amd64).

**IAM.** Execution role (pull image, logs, read the three secrets); api task role (PutObject `raw/*`); worker task role (GetObject `raw/*`, PutObject `hls/*`). No access keys anywhere.

**CloudWatch Logs.** `/ecs/minflix-prod-api`, `/ecs/minflix-prod-worker`, 14 days.

## dev → prod mapping
| dev (docker compose in minflix-be) | prod (this repo) |
|---|---|
| Vite dev server :5173 | S3 frontend bucket + CloudFront `/` |
| API container / IDE :8080 | ECS Fargate service `api` behind ALB, CloudFront `/api/*` |
| worker container | ECS Fargate service `worker` |
| MongoDB container | Amazon DocumentDB |
| RabbitMQ container :5672 | Amazon MQ for RabbitMQ (amqps :5671) |
| MinIO bucket `minflix` | S3 media bucket `minflix-prod-media-<suffix>` |
| MinIO anonymous read on `hls/` | CloudFront `/hls/*` with OAC (bucket stays private) |
| MinIO static credentials | ECS task roles |
| `application-dev.yml` values | env vars + Secrets Manager (contract table) |
| none | CloudFront CDN, ALB, ECR, CloudWatch Logs |
